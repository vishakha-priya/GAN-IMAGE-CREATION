# GAN-IMAGE-CREATION
In This Project Image is being generated using Vallina GAN
Here we, have a Generator class which generate the fake images with the helps of random number and a discriminator class which classify if the image generated by the 
generator is real or fake .

We have used celeba data set to get the real image to feed the discriminator. Transform the Real image , convert to tensor data and load to the dataloader

build the generator class which generate the fake image with the help of random number generated and then these numbers are passed through fully connected layer to  upsample and 
generate 3 channel image .

build the discriminator class to identify if the image generated by the generator is fake or real discriminator is also passed with some real images to learn and identify the 
fake and real image differnce .In discriminator the images generated by the generator is being passed through the fully connected layer to downsampled the image and 
classify as real or fake images.

define the optimizer for the generator and discriminator and also define the loss function for both 

train the discriminator generate the image from the generator then pass the real and fake image to the discriminator and generate the loss
for generator training we calculate the loss of generator on the basis of if the discriminator is identifying the image as real or fake 

training of the discriminator and generator occurs in multiple epochs 

finally save the images generated by the generator in different images and use matplotlib to display the images .
